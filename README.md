# Jump-Super-Stars-PC-Android-Browser-port-
A static recompilation of the Nintendo DS game *Jump Super Stars*. The game's ARM9 code, its overlays and the ARM7 sound/IO code are translated ahead of time into C++ and run on a reimplementation of the DS hardware (2D and 3D graphics, sound, DMA, timers, game card and save chip, touch screen, RTC). No BIOS or firmware dump is needed.
